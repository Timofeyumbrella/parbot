# Getting started with Parbot

Parbot turns your documentation into an assistant. Readers ask a question in plain language and get an answer drawn from your docs, with the pages it used listed underneath. You get every conversation in an inbox, plus the questions your docs could not answer.

## What you need

- A Parbot account. The Hobby plan is free and needs no card.
- Documentation to point it at: a public docs site, a sitemap, PDF or Word files, Markdown, or text you paste.
- About ten minutes.

## The three steps

1. **Create an assistant.** An assistant is one knowledge base plus one widget. Most products need one; agencies and multi-product companies create one per product.
2. **Add sources.** Open Knowledge and add a website, a sitemap, a file or pasted text. Parbot crawls, cleans and indexes the pages. Indexing runs in the background and the page shows progress.
3. **Try it, then install it.** Open Chat to ask questions as your readers would. When the answers look right, open Widget, copy the one-line script tag and add it to your site.

## What happens to a question

When a reader asks something, Parbot finds the passages in your docs closest in meaning to the question, sends only those passages to the model, and streams back an answer that cites them by number. If nothing in the docs covers the question, the assistant says so instead of guessing, and the question is recorded as unanswered so you can write the missing page.

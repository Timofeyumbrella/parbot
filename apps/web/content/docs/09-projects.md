# Projects

Projects group chats in the Chat sidebar, like folders. Each project can hold its own files and instructions, and every chat inside it answers with them. Use one per topic you keep coming back to: a billing project that always reads the pricing sheet, an onboarding project that answers for new customers.

## Creating a project

In Chat, choose **New project** under Projects, type a name and press Enter. The project shows in the sidebar at once and its home opens: its instructions, its files, its latest chats, and a message box that starts a new chat inside it. A name can be up to 60 characters, and two projects cannot share one.

Each project is a folder in the sidebar. The arrow opens it to show its chats, newest first, and the number beside it counts them. The project's name opens its home. Its menu offers **New chat in this project**, **Edit project**, **Rename** and **Delete**.

## Files and instructions

Open **Edit project** from the project's home or its menu.

- **Files.** Pick files and sources from Knowledge, from the same list the @ picker shows, or attach new files. An attached file is added to Knowledge like any upload and counts toward your plan's pages; you can save the project while it uploads. A project holds up to 20 files.
- **Instructions.** Up to 4,000 characters, for example "Answer for the billing team and lead with the plan name". They are added after the assistant's own instructions from Settings and shape the focus and tone of answers. They cannot make the assistant answer from anything but your sources: when the sources do not cover a question, it still says so.

Every question in a project reads the project's files first, even when the question does not name them, the same way a file picked with @ is read (see "Pointing a question at a file" in Sources and indexing). With many files, each file's best passage comes before any file's second, and the passages closest to the question are the ones that fit. In a chat inside a project, the message box shows the project's name and its files as fixed chips; they change in the project, not per message. You can still point a question at other files with @ or the paperclip, and they are read alongside the project's.

## Moving chats in and out

Choose **Move to project** in a chat's menu and pick a project, or drag the chat onto a project's folder. **Remove from project** in the same menu takes it out again, as does dragging it onto Chats. The chat keeps its messages; from its next question on, it answers with the files and instructions of the project it is in now.

## Deleting a project

**Delete** removes the project and its instructions after you confirm. Its chats are not deleted: they move to Chats and keep their messages. Its files stay in Knowledge.

## Where projects show up

The Inbox labels chats that belong to a project, in the list and on the transcript. Projects belong to the in-app chat: the widget does not use them, and visitors never see a project's files or instructions.
